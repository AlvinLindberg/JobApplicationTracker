# JobApplicationTracker

## Projektbeskrivning
JobApplicationTracker är en C#-konsolapplikation som hjälper användaren att hålla koll på sina jobbansökningar. Programmet använder objektorienterad programmering (OOP), listor och LINQ.

## Funktioner
- Registrera nya jobbansökningar.
- Visa och uppdatera ansökningar.
- Filtrera och sortera ansökningar.
- Visa statistik över jobbansökningar.

## Så kör du programmet
1. Öppna projektet i Visual Studio.
2. Starta programmet med F5.
3. Följ instruktionerna i konsolmenyn.

**1. Hur hjälpte LINQ dig att skriva renare kod?**

LINQ gör det enklare att filtrera, sortera och beräkna information från listor utan att behöva skriva lika många loopar.
